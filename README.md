## Pembukaan

Repository ini berisi semua kode yang digunakan dalam praktikum pemrograman multiplatform, mulai dari pengenalan dart, flutter sampai membuat sebuah aplikasi mobile yang terhubung dengan RESTful API.

### Daftar Materi

Berikut ini adalah daftar materi yang dipelajari

- Pengenalan Dart
- Pemrograman Berorientasi Objek
- Widget
- Form dan Validasi
- Rute dan Navigasi Layar
- Akses Fitur Native
- Akses RESTful API
- Pengenalan Flutter
- Dasar-dasar Flutter
- Widget Lanjutan
- Membuat Aplikasi Web dan Mobile Sederhana
